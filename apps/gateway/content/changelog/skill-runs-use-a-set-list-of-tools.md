---
title: "A scheduled skill run uses a set list of tools"
date: "2026-10-26"
tags: ["skills", "agent"]
---

A skill run asks you nothing while it works, so it now gets a narrower set of tools than a chat. It
can use the connector tools its skill names, and the built-in tools that only read. It can no longer
edit or delete skills, or disconnect an account. A built-in tool added later as a write is left out
of skill runs without anyone having to remember to.
