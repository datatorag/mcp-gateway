---
title: "A real page when a link is broken"
date: "2026-09-20"
tags: ["site"]
---

A mistyped address, or a link to something that has since moved, used to land on the bare
default page our framework ships. It said the page was not found and offered nothing else, in
type that did not match anything around it.

There is a proper page there now. It says what happened in a sentence and puts a link to the
home page under it, so a broken link is a detour rather than a dead end. It looks like the rest
of the site because it is now part of it.

Nothing else changes. Addresses that worked yesterday work today.
