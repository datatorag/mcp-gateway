There is a new page of use cases: things you can ask an agent to do with your work tools through
DataToRAG, such as a morning brief across every inbox, an email thread turned into a Jira issue,
or rows found and updated in a spreadsheet.

Each one has its own page. A replay shows the request the way it runs: the prompt, each step the
agent takes with the tool it uses, and what comes back. The same steps are written out under it,
with a prompt you can copy and the docs for each tool.

Find them under Solutions in the menu, or at [/use-cases](/use-cases).
