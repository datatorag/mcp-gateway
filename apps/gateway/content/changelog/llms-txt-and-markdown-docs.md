---
title: "The docs as Markdown, a list of them at /llms.txt, and a link to every section"
date: "2026-11-25"
tags: ["site"]
---

An agent that reads our docs no longer has to pick the text out of a web page.

- **[/llms.txt](https://datatorag.com/llms.txt) exists.** It names the product in a paragraph and lists every
  docs page and every use case, each with its one-line description and a link.
- **Every docs page has a Markdown copy at the page's address plus `.md`.** The Gmail page is
  `https://datatorag.com/docs/gmail`, and its copy is `https://datatorag.com/docs/gmail.md`: the same
  title, description, date, body, and questions, with every link written in full. The docs index, the
  [list of every tool](/docs/tools), and each [use case](/use-cases) have a copy the same way. A copy is made
  from the same file as its page, so the two say the same thing.
- **Sections can be linked.** Every heading on a docs page has an address of its own. Hover a heading, or
  tab to it, and a `#` appears beside it: that link opens the page at that section.
