title: "A new dashboard home: connect your agent first"
date: "2026-11-09"
tags: ["dashboard"]
---

The dashboard home now starts with the thing a new account needs first: getting DataToRAG into
the assistant you already use.

- **Client cards.** Claude.ai, Claude Desktop, Claude Code, ChatGPT, Codex and Cursor each get a
  card with the exact setup for that client: a URL to paste, a command to run, or for Cursor an
  Install link that fills the config in. Each card links to the full setup page for the long form.
- **Your MCP server.** The server URL with a copy button, and the clients it works in.
- **Things to ask.** The example prompts moved up the page, each tagged with the services it uses.
  They run in the agent once an account is connected.
- **Your accounts.** One chip per provider, Connected, Not connected or Needs reconnecting, each
  linking to the new Connections page.
- **Connections has its own page.** The connection cards that used to be the home are now at
  Dashboard, then Connections, with a sidebar item of their own.

With no account connected, the page says so above the client cards and keeps everything visible:
set up your client and connect an account in whichever order you like, and connect at least one
account before the first call.
