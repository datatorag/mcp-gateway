Two new skills in the [skills library](/skills), for the moment Claude writes the right content
into a Google Doc or Sheet and it comes out unreadable.

- **[Google Doc formatting](/skills/google-doc-format).** A title, real headings that build the
  outline, bold, bulleted lists and links, styled through the Docs API in one pass after the text
  is written.
- **[Google Sheet formatting](/skills/google-sheet-format).** Column widths, wrapped text, a
  frozen header, section bands and your fonts, applied after the values are in.

Each one keeps the notes from running it, including what went wrong on the way: a body font that
silently removed every bold phrase, five hand-counted ranges that were all wrong, a frozen column
that blocked a merge and took a whole formatting batch with it, and a cleared tab that quietly
dropped seven cells of a row.
