---
title: "API keys are gone; every client connects with OAuth"
date: "2026-10-26"
tags: ["auth", "oauth"]
---

DataToRAG no longer has API keys. Every client connects with OAuth: you add the server URL to
Claude, Claude Code, Cursor or ChatGPT, sign in once, and the client keeps its own access fresh.

The API keys page is gone from the dashboard, and a key that was made before this change no
longer works. To connect a client, follow the [getting started guide](/docs/getting-started).
