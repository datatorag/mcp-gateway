---
title: "One click to sign in"
date: "2026-10-10"
tags: ["dashboard", "site"]
---

Every **Get started**, **Start free**, **Sign in** and **Run this skill** button on the site
now opens Google sign-in directly. There used to be a page in between with a single
"Continue with Google" button on it. It asked for a second click to do what the first one
already meant, and some people never made it past.

What changed around that:

- **The button shows it heard you.** Handing over to Google takes a moment. The button now
  dims while that happens and ignores a second click, where before it looked as if nothing
  had happened.
- **You still land where you were going.** A skill's Run button still ends in the agent with
  that skill loaded, and the Pro button on the pricing page still comes back to pricing.
- **If sign-in does not finish, you get a way back.** Closing Google's screen used to end on
  a bare line of error text. It now returns to the sign-in page with a note and the button.
- **Terms and privacy are stated where you sign in.** The sentence that lived on the old page
  now sits beside the main sign-up buttons and on the first screen of the dashboard, with
  links to both documents.

The sign-in page itself is still there. It is where you arrive if a session expires while a
dashboard page is open, or if a sign-in is interrupted.
