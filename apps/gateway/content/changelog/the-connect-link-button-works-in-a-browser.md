date: "2026-11-04"

Pressing the button on a connect link opened from inside a conversation answered with an empty
error page instead of going on to the provider's consent screen, so an account could not be
connected that way from a browser. It now goes straight on. The link still works once, still
expires after ten minutes, and its address still never reaches another site.
